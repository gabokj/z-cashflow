DRIVER JDBC DO MYSQL (obrigatorio para executar o sistema)

1. Baixe o MySQL Connector/J (opcao "Platform Independent", arquivo .zip):
   https://dev.mysql.com/downloads/connector/j/
2. Extraia o .zip e copie o arquivo mysql-connector-j-8.x.x.jar para esta pasta (lib/).
3. No NetBeans: clique com o botao direito em "Libraries" > "Add JAR/Folder"
   e selecione o .jar (ou use "Add Library..." > "MySQL JDBC Driver", que ja vem com o NetBeans).

O projeto esta configurado para o arquivo lib/mysql-connector-j-8.4.0.jar; se voce
baixar outra versao 8.x, use "Add JAR/Folder" e remova a referencia antiga.
O codigo-fonte compila mesmo sem o driver; ele so e necessario para executar.
