# Z-CashFlow — Projeto de Usabilidade e Interfaces (UX/UI)

Projeto Integrador — Etapa 2

## Conteúdo deste pacote

- `Z-CashFlow_Projeto_UXUI.docx` — documento completo do projeto: personas,
  fluxo de navegação, wireframes, paleta de cores, tipografia e
  considerações de acessibilidade (comece por aqui).
- `wireframes/` — 5 telas em baixa fidelidade (PNG + fonte SVG editável):
  Login, Dashboard, Cadastro de Movimentação, Extrato, Categorias.
- `mockups/` — 2 telas em alta fidelidade com a paleta de cores aplicada
  (Dashboard e Cadastro de Movimentação), além da folha de referência da
  paleta de cores (`paleta_cores.png`).

## Observação sobre a ferramenta

As telas foram desenhadas vetorialmente (SVG, editável em qualquer editor
vetorial ou diretamente como código) em vez do Figma, mas seguem os mesmos
princípios de um projeto de wireframe/mockup: hierarquia visual, grid,
paleta de cores consistente e anotações de acessibilidade — prontos para
serem recriados no Figma ou usados diretamente como referência para a
programação das telas em Java (Swing/JavaFX).
